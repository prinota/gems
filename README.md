# GEMS - Игра "Три в ряд"

## Инструкция по запуску

Восстановите пакеты NuGet:
   - В Solution Explorer нажмите правой кнопкой на Solution
   - Выберите "Restore NuGet Packages"
   - SFML установится автоматически

### Бонусы
- При уничтожении квадратов могут выпасть бонусы:
  - Золотой — перекрашивает 3 квадрата в один цвет
  - Красный — уничтожает 5 случайных квадратов
